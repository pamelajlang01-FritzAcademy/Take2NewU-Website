# Take2NewU Website

Production website source for Take2NewU, LLC.

## Current build

- Responsive brand-led homepage
- Wellness pathways
- Brand family section
- Shopify store links
- Education/"The Next Chapter" section
- Accessible mobile navigation

## Local preview

Open `index.html` directly in a browser, or use the VS Code Live Server extension.

## Architecture

- WordPress remains the content-management system for future articles and editable company content.
- Shopify remains the commerce, checkout, payment, order, shipping, and customer-account platform.
- This repository is the controlled design and front-end source for the Take2NewU website.
