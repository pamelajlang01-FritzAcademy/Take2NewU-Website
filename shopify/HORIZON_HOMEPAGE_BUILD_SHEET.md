# Take2NewU Shopify Horizon Homepage Build Sheet

## Purpose
The custom Take2NewU website remains the company front end. Shopify is the shopping experience. This build sheet gives the exact Horizon homepage structure so the next Mac session is execution only.

- Soft champagne: #F2E5CF
